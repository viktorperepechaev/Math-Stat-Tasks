# T.10

Сгенерируйте выборку из N(0, 1) размера 1000. Преобразуйте выражение

Dₙ = supₓ∈ℝ |Fₙ(x) − F(x)|

так, чтобы вместо supₓ∈ℝ получился максимум по конечному множеству.

Постройте график зависимости Dₙ от n при 1 ≤ n ≤ 1000. Верно ли, что у последовательности Dₙ есть предел? Если да, то чему он равен и как называется соответствующий вид сходимости?

Найдите с помощью выборки приближенное значение P(√n Dₙ ≤ x) при x ∈ [−1, 10] и постройте график этой функции. Изобразите на том же графике функцию распределения K(x), соответствующую распределению Колмогорова.
